# Quiet is not a grey wash

**Status:** still in force. **Evidence:** Harris's correction after 1.2.2; the 1.2.1 spent-only picker; a 1.2.2 full-greyscale reading that washed healthy rings.

Quiet means **keep green for OK, replace alarm red with grey**. It is Red alert's two-band language with the red swapped for muted grey — not a third ladder that maps every fraction onto grey.

1.2.1's spent-only Quiet only overrode the spent hue, so 98% used (2% remaining) still went red through the old green→amber→red climb. 1.2.2 made the scheme the vocabulary, then misread Quiet as "a neutral grey scale by usage." That washed the healthy band: a Cursor ring at 93% remaining went grey while Codex at 2% remaining could still read red on a path that had not yet been rewritten. Both halves were wrong.

The rule: below `warningThreshold` → `pulseGood` (the same green Red alert uses). At or above it, or when the provider says spent → `pulseQuiet` / `pulseQuietDeep`. Never red, never amber, and never grey because the ring is merely in use.
